# Zomato Review Analysis using NLP

This project performs sentiment analysis on Zomato food reviews using Natural Language Processing (NLP) techniques in Python. The goal is to classify user reviews as positive or negative based on their textual content.

---

##  Project Highlights

- Text preprocessing using `regex`, `stopwords`, and `stemming`
- Feature extraction using `CountVectorizer`
- Classification model for sentiment prediction
- Real-world food review dataset from Zomato
- Model performance visualization (optional)

---

 ## Technologies 

- Python
- Pandas, NumPy
- NLTK (Natural Language Toolkit)
- Scikit-learn

---

## 📝 Features

- Cleans and tokenizes text
- Removes stopwords and punctuation
- Applies stemming to normalize words
- Converts text to numerical features
- Trains and tests a classifier to predict sentiments
